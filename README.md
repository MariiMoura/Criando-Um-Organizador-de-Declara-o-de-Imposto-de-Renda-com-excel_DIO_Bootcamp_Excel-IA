# 📋 Organizador de Dados para Declaração de Imposto de Renda

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio prático da DIO com o objetivo de criar uma ferramenta em Excel para auxiliar na organização das informações necessárias para a declaração do Imposto de Renda.

A solução concentra dados importantes em um único arquivo, facilitando o controle das informações financeiras do usuário por meio de menus de navegação, validações automáticas e recursos que tornam o processo mais simples, seguro e eficiente.

## 🎯 Objetivos do Projeto

- Centralizar informações relevantes para a declaração do Imposto de Renda.
- Aplicar conceitos avançados de Excel em um projeto prático.
- Melhorar a organização e o controle de dados financeiros.
- Utilizar recursos de validação para reduzir erros de preenchimento.
- Desenvolver uma interface intuitiva para navegação entre as áreas da planilha.

## 🛠️ Funcionalidades

A ferramenta possui recursos como:

✅ Menu de navegação entre as seções da planilha;

✅ Cadastro organizado de informações pessoais;

✅ Registro de rendimentos;

✅ Controle de contas bancárias;

✅ Registro de bens e patrimônios;

✅ Validações automáticas de dados;

✅ Links rápidos para facilitar a navegação;

✅ Estrutura preparada para apoiar a declaração anual do Imposto de Renda.

## 📊 Recursos do Excel Utilizados

Durante o desenvolvimento foram aplicados diversos recursos da ferramenta:

- Validação de Dados;
- Formatação Condicional;
- Fórmulas e Funções;
- Hiperlinks;
- Organização em tabelas;
- Proteção e controle de células;
- Navegação entre planilhas.

## 🚀 Como Utilizar

1. Baixe o arquivo `Organizador_IR.xlsx`.
2. Abra a planilha no Microsoft Excel.
3. Utilize o menu principal para acessar as áreas disponíveis.
4. Preencha as informações solicitadas em cada seção.
5. Utilize os campos validados para evitar erros de preenchimento.
6. Mantenha os dados atualizados durante o ano para facilitar a declaração do Imposto de Renda.
